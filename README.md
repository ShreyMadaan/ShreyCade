# ShreyCade

ShreyCade is a full-stack multiplayer gaming platform
where players can compete online, challenge friends,
or play against AI bots.

## Planned Games

- Tic-Tac-Toe
- Chess
- Ludo
- Business

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MongoDB Atlas

## Project Structure

- client/ - Frontend
- server/ - Backend
- shared/ - Shared game contracts
- docs/ - Documentation
